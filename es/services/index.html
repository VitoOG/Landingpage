GOLDEN GREENS CROP / SERVICIOS DE INGENIERÍA

Ingeniería, desde la arquitectura hasta la integración.

Trabajo técnico acotado, con entregables definidos, límites de alcance y criterios de aceptación acordados.

El alcance y el precio final se acuerdan antes de comenzar el trabajo.

ÁREA AEVALUACIÓN

Evaluación de arquitectura e integración de sistemas

Para sistemas cuyos componentes ya existen, pero cuyas interfaces, dependencias, requisitos o límites de fallo necesitan mayor claridad.

Resultados habituales

  • Contexto del sistema y mapa de interfaces
  • Revisión de requisitos e integración
  • Hallazgos respaldados por evidencias y registro de riesgos
  • Arquitectura objetivo y prioridades de verificación
ÁREA BDISEÑO

Integración de datos IoT industrial / OT–IT

Diseño de una ruta mantenible desde sensores y controladores hasta monitorización local, servicios de datos y aplicaciones de nivel superior.

Resultados habituales

  • Mapa de flujo de datos dispositivo-servicio
  • Responsabilidades de pasarelas e interfaces
  • Modelo de telemetría y contrato de datos
  • Plan de conectividad, fallos y pruebas
ÁREA CPROTOTIPADO

Prototipos embedded y edge

Integración de microcontroladores, sensores, adquisición de datos, interfaces de actuadores y software local en un prototipo verificable.

Resultados habituales

  • Definición de interfaces y arquitectura del prototipo
  • Integración de hardware y software acordada
  • Pruebas funcionales y registro de incidencias
  • Documentación técnica y siguientes pasos
ÁREA DI+D APLICADA

Instrumentación CEA / AgTech

Arquitectura de medición ambiental y de la zona radicular, inventario de sensores, planificación de calibración y trazabilidad de experimentos.

Resultados habituales

  • Arquitectura de medición e inventario de sensores
  • Plan de calibración y muestreo
  • Esquema de datos y trazabilidad de mediciones
  • Protocolo piloto y revisión de calidad de datos

La implementación, el trabajo con hardware, la instalación y la puesta en marcha se definen por separado después de acordar las restricciones, responsabilidades y criterios de aceptación.
